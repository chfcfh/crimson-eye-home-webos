# Crimson Eye Home for LG webOS

This personal fork starts from the MIT-licensed CleanYourTV-WebOS project. It keeps the existing reversible Home takeover and adds a red anime-inspired launcher treatment for rooted LG webOS TVs.

## Design and behavior

- Original crimson moon wallpaper with a dark lower area for the app row.
- Minimal app dock, red focus light, and an original eye emblem that follows the selected tile.
- The selected app grows, its name appears below it, and the eye blinks at random intervals.
- The eye spins when Home appears or regains focus; launching an app gets a short zoom transition.
- The existing Wallpapers feature can rotate photos. Add at least two photos and enable rotation in the launcher to use that feature; this fork does not turn photo rotation on automatically.

The project uses the original CleanYourTV service and changes its launcher page. It does not install the Android/Google TV launcher from the reel.

## Build

```sh
node tools/build-pages.js
node tools/theme-index.js
node tools/test.js theme
python3 ipk/build.py
```

The Homebrew Channel feed generated by `ipk/build.py` points to the GitHub repository named by `CYTV_REPO`. A GitHub release is needed before the TV can install that feed. Do not set up the launcher on a TV until the package has been installed and its preview has been reviewed.

## Files changed

- `themes/crimson-eye/`: theme values, original wallpaper, and the approved design preview.
- `app/src/js/focus-eye.js`: focus-following emblem, random blink, wake spin, and focused app label.
- `app/src/js/theme.js`, `tiles.js`, `index.html`, and `css/home.css`: integrate the effect with the existing focus, glow, and dock.
- `tools/theme-preview.mjs`: use Windows-safe file URL handling and discover Chrome on Windows.
